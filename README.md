# Conversor de Unidades em C

Programa desenvolvido em linguagem C para conversão rápida de diversas grandezas físicas (Comprimento, Massa, Temperatura, Área e Volume), criado por **Domingos Cunha**.

## Requisitos do Sistema
* Compilador C compatível (como **Clang** ou **GCC**).
* Visual Studio Code configurado.

## Instalação e Configuração no VS Code
1. Tem de ter o **Clang** (ou LLVM) instalado e nass variáveis de ambiente.
2. Abrir a pasta do projecto no **Visual Studio Code**.
3. Criar uma pasta chamada ".vscode" na raiz do projeto e colocar o ficheiro "tasks.json" com a configuração de compilação.

## Compilação e Execução
1. Abrir o ficheiro `Conversor.c` no VS Code.
2. Carregar **Ctrl + Shift + B** para compilar o programa usando a tarefa predefinida.
3. No terminal integrado, execute o binário gerado:
   * **Windows:** `.\Conversor.exe`
   * **Linux / macOS:** `./Conversor`
